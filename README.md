# tg_botik

Телеграм-бот для самопроверки персональных данных на предмет утечек.

Проверяет **только данные самого пользователя** и только после подтверждения
владения ими (код на email, кнопка «Поделиться контактом» для телефона).

Подробная инструкция по установке, настройке и использованию —
в [INSTRUCTION.md](INSTRUCTION.md).

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить токен, ключ HIBP и SMTP
python bot.py
```
